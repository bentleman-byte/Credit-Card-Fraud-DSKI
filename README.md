# Credit-Card-Fraud-DSKI
Gruppenprojekt im Studiengang Data Science und Künstliche Intelligenz an der DHBW Karlsruhe.

In diesem Projekt wird ein Kaggle Datensatz (https://www.kaggle.com/datasets/marusagar/bank-transaction-fraud-detection?resource=download) zum Thema "Bank Transaction Fraud Detection" analysiert.
Dabei wird der Datensatz erklärt, die Variablentypen bestimmt, sowie auch eine Analyse durchgeführt um zu sehen, welche Variablen einen Betrug kennzeichnen könnten.
